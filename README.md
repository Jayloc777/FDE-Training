## 推荐打开方式

1. 先将整个 ZIP 压缩包解压到本地文件夹。
2. 打开 `FDE人才培养体系门户.html`。
3. 不要只单独转发或单独打开某一个 HTML；门户页面需要同目录下的 `fde-curriculum.css` 和 `fde-curriculum.js` 才能保留完整渲染与交互。
4. 不要重命名、移动或删除同目录文件。

推荐使用最新版 Chrome 或 Microsoft Edge。课程正文、场景卡、搜索和筛选功能可以离线查看；15 张练习卡的外部参考来源需要联网后打开，24 张 Datawhale 案例卡附带本地 PDF 原件，可离线追溯页码。

## 场景库说明

门户中的场景库分为两层：15 张可选练习卡和 24 张 Datawhale 真实案例卡。练习卡包含业务流程痛点、FDE 切口、L1 Demo 输入输出、练习任务、建议测试、安全边界和参考来源；案例卡保留案例标题、行业、负责人、原始 PDF 页码、Q1–Q6 负责人 QA 摘要，以及面向 L1 的练习转译。点击“选作练习”后，可以在门户右侧工作台中生成该场景的练习简报；案例卡支持按行业筛选、关键词搜索和展开 QA。

场景库使用官方或行业标准资料作为流程依据；具体 Demo 切口、作业和 L1 边界属于课程设计推断，不能替代行业法律、合规制度、数据授权或生产审批。

## 分享边界

本分享包包含课程体系、练习资料和 `Datawhale FDE案例100.pdf` 原始 PDF；不包含原始 `L1初版.xmind`、`参考资料\归档` 或其他内部归档物料。原始 XMind/归档资料仅作为本次课程整合的设计依据，未被修改。
